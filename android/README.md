# Клиент для Android

Приложение — тонкая оболочка вокруг того же ядра, что работает на Linux. Весь код внутри
`internal/client`; здесь только то, чего на сервере не бывает: запрос разрешения у системы,
получение интерфейса от `VpnService` и экран, куда вставляют бандл.

## Как оно устроено

Приложение просит систему создать интерфейс и получает от неё **готовый дескриптор**. Прав
создавать своё устройство у приложения нет и не должно быть; адреса, маршруты и службу имён
система расставляет сама по тому, что у неё попросили в `QdVpnService.startTunnel`. Ядру
достаётся только дескриптор — читать и писать пакеты.

Собственное соединение с узлом выводится из туннеля целиком: `addDisallowedApplication` на
самих себя. Иначе связь с входным узлом ушла бы в туннель, который через эту же связь и
работает, — та же петля, что однажды отрезала сервер от сети, только чинится проще.

Резолвер в туннеле — `198.18.0.1`, второй адрес подменного диапазона. Адрес самого интерфейса
для этого не годится: система считает его своим и до нашего стека пакеты не доводит.

## Сборка

```
powershell -File android\build.ps1
```

Gradle не нужен и не используется. Приложение — два класса и манифест, а инструменты
(`aapt2`, `d8`, `apksigner`, `zipalign`) лежат в Android SDK. Gradle принёс бы сотню мегабайт
зависимостей и свой жизненный цикл ради четырёх вызовов.

Что должно стоять:

- Android SDK с `build-tools 34.0.0` и `platforms/android-34`;
- NDK (проверено на 27.2) — его требует `gomobile`;
- JDK 17;
- `gomobile` и `gobind`: `go install golang.org/x/mobile/cmd/gomobile@latest`, затем
  `gomobile init`.

Другая архитектура задаётся переменной: `$env:QD_ABI = 'armeabi-v7a'`.

Ключ подписи (`debug.keystore`) создаётся при первой сборке и лежит рядом со скриптом — не в
`build`, который вычищается. Сменившаяся подпись означала бы, что приложение не встаёт поверх
прежнего.

## Установка

```
adb install -r build\qdiver.apk
```

На прошивках Xiaomi это может закончиться `INSTALL_FAILED_USER_RESTRICTED`: там установка по
USB запрещена отдельной настройкой в параметрах разработчика. Обходной путь — положить пакет
на телефон и поставить руками:

```
adb push build\qdiver.apk /sdcard/Download/qdiver.apk
```

## Чего пока нет

Экран настроек. Из-за этого на телефоне отключены базы `geosite`/`geoip` (качать двадцать
восемь мегабайт по сотовой сети без спроса — дурной тон) и вход SOCKS (на телефоне его некому
показывать). И то и другое включится вместе с настройками.
