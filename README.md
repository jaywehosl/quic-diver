# QUIC Diver

Прокси-протокол на QUIC. Узлы под Linux, клиенты под Android и Windows.

Децентрализованная сеть автономных узлов, разделённых на входные и выходные. Управляющий трафик
идёт внутри того же транспорта, что и полезный: отдельных портов, демонов и каналов управления
нет. Узел снаружи выглядит обычным сайтом на HTTP/3 — тот, кто пришёл без подписи, получает
страницу-заглушку, как на любом несуществующем адресе.

Строгое следование RFC/IETF: без обхода и обмана DPI, без маскировки под чужой трафик.

## Состав

| Путь | Что |
|------|-----|
| `cmd/qd-node` | узел |
| `cmd/qd-client` | клиент под Linux и Windows, вход SOCKS5 и туннель |
| `cmd/qd-admin` | управление сетью из командной строки |
| `internal/` | ядро: QUIC, журнал, маршрутизация, служба имён |
| `mobile/`, `android/` | приложение под Android поверх того же ядра |
| `deploy/` | развёртывание узла |
| `third_party/` | форк quic-go и `wintun.dll` под Windows |

## Сборка

Нужен Go 1.26+.

```bash
go build ./...
```

Приложение под Android — `android/build.ps1`: собирает ядро через gomobile и передаёт Gradle.
Нужны JDK 17, Android SDK 34 и NDK.

За прокси Gradle системные переменные `HTTP_PROXY` не читает — свойства кладутся в
`~/.gradle/gradle.properties`.

## Зависимости

| Модуль | Версия | Роль |
|--------|--------|------|
| `github.com/quic-go/quic-go` | v0.61.0, форк | QUIC и HTTP/3 |
| `github.com/quic-go/masque-go` | v0.4.0 | CONNECT-UDP (RFC 9298) |
| `gvisor.dev/gvisor` | ветка `go` | netstack: клиент терминирует TCP локально |
| Wintun | 0.14.1 | TUN-адаптер под Windows |

`gvisor` собирается только из ветки `go`: `go get gvisor.dev/gvisor@go`. Master и релизные теги
как Go-модуль не собираются.

## Лицензионная оговорка

`wintun.dll` — проприетарный бинарь WireGuard LLC. Распространять можно только рядом с ПО,
использующим его исключительно через API из `wintun.h`; изменять dll нельзя. См.
`third_party/wintun/LICENSE.txt`.
